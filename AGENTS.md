# Agent instructions

The project rules live in `docs/rules/`. Read them before changing code:

- `docs/rules/architecture.md`: where code goes, routes, dependency rules
- `docs/rules/code-style.md`: Zod-first types, naming, results and errors
- `docs/rules/forms.md`: native forms, contracts, enhancers
- `docs/rules/testing.md`: E2E only, page objects, mocked AI
- `docs/rules/workflow.md`: issues, labels, branches, PRs

`CLAUDE.md` imports the same files for Claude Code.
